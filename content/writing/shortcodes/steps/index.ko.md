`steps` 숏코드는 DaisyUI의 steps 컴포넌트를 사용하여 가로 방향의 단계 표시기를 만들며, 다단계 프로세스의 진행 상황을 표시하는 데 완벽합니다.

## 사용법

```jinja
{{/* steps(steps=["회원가입", "플랜 선택", "구매", "제품 수령"], completed=2) */}}
```

## 매개변수

- `steps` (필수): 각 단계 레이블을 나타내는 문자열 배열
- `completed` (선택): 완료된 단계 수 (기본 색상으로 강조 표시됨). 기본값은 0
- `data_content` (선택): 각 단계 표시기에 표시할 사용자 지정 콘텐츠 문자열 배열 (예: ["✓", "✓", "★", "4"])

## 예제

### 기본 가로 단계

{{ steps(steps=["회원가입", "플랜 선택", "구매", "제품 수령"], completed=2) }}

```jinja
{{/* steps(steps=["회원가입", "플랜 선택", "구매", "제품 수령"], completed=2) */}}
```

### 사용자 지정 데이터 콘텐츠가 있는 단계

{{ steps(steps=["이메일 발송", "이메일 열람", "링크 클릭", "구매"], completed=2, data_content=["✓", "✓", "★", "4"]) }}

```jinja
{{/* steps(steps=["이메일 발송", "이메일 열람", "링크 클릭", "구매"], completed=2, data_content=["✓", "✓", "★", "4"]) */}}
```

### 모든 단계 완료

{{ steps(steps=["시작", "처리 중", "완료"], completed=3) }}

```jinja
{{/* steps(steps=["시작", "처리 중", "완료"], completed=3) */}}
```

## 기능

- **가로 레이아웃**: 단계가 가로 행으로 표시됩니다
- **진행 표시**: `completed` 매개변수를 사용하여 완료된 단계를 강조 표시합니다
- **사용자 지정 아이콘**: `data_content` 배열을 사용하여 단계에 사용자 지정 아이콘 또는 숫자를 추가합니다
- **반응형**: 다양한 화면 크기에 맞게 조정됩니다
- **시각적 피드백**: 완료된 단계와 남은 단계를 명확하게 표시합니다

## 참고사항

steps 컴포넌트는 DaisyUI의 기본 제공 steps 스타일을 사용합니다. `completed` 숫자까지의 단계는 기본 색상으로 강조 표시되고, 나머지 단계는 중립 상태로 유지됩니다.
