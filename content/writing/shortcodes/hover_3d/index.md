`hover_3d`

- `hover_3d`: Shows an image with a 3D hover effect.  
  Parameters:  
  - `src`: The path to the image file.  
  - `alt`: (Optional) Alt text for the image. Defaults to "Hover 3D image".

{{/* hover_3d(src="/images/example.png", alt="Example image") */}}
